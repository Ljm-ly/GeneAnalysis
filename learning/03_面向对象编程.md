## 3.1 用生活例子理解"类"和"对象"

### 类 = 模具/概念

想象你要做很多个一模一样的月饼。先做一个**模具**（类），然后用模具批量生产**月饼**（对象）。

| 类（模具） | 对象（实物） |
|-----------|-------------|
| "狗"这个概念 | 你家的"旺财" |
| "汽车"这个概念 | 你的"特斯拉" |
| "手机"这个概念 | 你的"iPhone" |

**类的组成**：
- **属性**：特征、数据（狗的名字、颜色）
- **方法**：能做的事（狗会叫、会跑）

### 代码中的对应关系

```python
class Dog:                    # 类 = 模具
    name = "旺财"             # 属性 = 特征
    color = "黄色"
    
    def bark():               # 方法 = 能做的事
        print("汪汪！")

my_dog = Dog()                # 对象 = 用模具造出来的实物
```

## 3.2 定义类的基础语法

### 最简单的类

```python
class Dog:
    """狗类"""
    pass   # pass 表示"什么也不做"，占位用
```

### 有属性和方法的类

```python
class Dog:
    """狗类"""
    
    def __init__(self, name, color):
        """初始化方法：创建对象时自动调用"""
        self.name = name
        self.color = color
        self.age = 0
    
    def bark(self):
        """叫的方法"""
        print(f"{self.name}在汪汪叫！")
    
    def run(self):
        """跑的方法"""
        print(f"{self.name}在跑！")
    
    def birthday(self):
        """过生日，年龄加1"""
        self.age += 1
        print(f"{self.name}现在{self.age}岁了！")
```

**关键字说明**：
- `class`：定义类
- `__init__`：**初始化方法**，创建对象时**自动**执行
- `self`：**对象自己**，代表"我这个对象"
- `self.name`：对象的**属性**（数据）
- `def bark(self)`：对象的**方法**（行为）

### 创建和使用对象

```python
# 创建对象（实例化）
dog1 = Dog("旺财", "黄色")
dog2 = Dog("来福", "黑色")

# 访问属性
print(dog1.name)    # 旺财
print(dog2.color)   # 黑色

# 调用方法
dog1.bark()         # 旺财在汪汪叫！
dog2.run()          # 来福在跑！

# 修改属性
dog1.birthday()     # 旺财现在1岁了！
print(dog1.age)     # 1
```

## 3.3 self 到底是什么？

这是初学者最容易困惑的概念。**其实很简单**：

> **self = 调用方法的那个对象**

### 图解

```
创建对象: dog1 = Dog("旺财", "黄色")

内存中:
  dog1 指向一个对象:
    ┌─────────────────────┐
    │  name: "旺财"       │  ← self.name 就是访问这个
    │  color: "黄色"      │  ← self.color 就是访问这个
    │  age: 0             │
    │                     │
    │  bark() 方法        │  ← dog1.bark() 时，self = dog1
    │  run() 方法         │
    └─────────────────────┘

调用: dog1.bark()
→ Python 自动把 dog1 传给 self
→ 方法内部 self.name 就是 dog1.name，即 "旺财"
```

### 为什么需要 self？

同一个类可以创建很多对象，self 帮助区分"这是哪个对象的数据"。

```python
dog1 = Dog("旺财", "黄色")
dog2 = Dog("来福", "黑色")

dog1.bark()   # 输出"旺财在汪汪叫！"，self = dog1
dog2.bark()   # 输出"来福在汪汪叫！"，self = dog2
```

**记住**：
- 定义方法时**必须写 self**（第一个参数）
- 调用方法时**不用传 self**（Python 自动传）

## 3.4 属性 vs 方法

| | 属性 (Attribute) | 方法 (Method) |
|---|-----------------|---------------|
| **是什么** | 数据、特征 | 行为、功能 |
| **像什么** | 名词 | 动词 |
| **怎么访问** | `对象.属性名` | `对象.方法名()` |
| **例子** | `dog.name` | `dog.bark()` |

```python
dog = Dog("旺财", "黄色")

# 属性：访问数据
print(dog.name)     # 旺财（名词，没有括号）
print(dog.age)      # 0

# 方法：执行操作
dog.bark()          # 旺财在汪汪叫！（动词，有括号）
dog.run()           # 旺财在跑！
```

**记忆口诀**：
- 属性 = **名词**（名字、颜色、年龄）→ **不加括号**
- 方法 = **动词**（叫、跑、吃）→ **加括号**

        """检查配置是否有效"""

            print("FASTA文件不存在！")
            return False
        return True
    
    # 方法：保存配置到文件
    def save_to_file(self, filepath):
        """保存配置"""
        with open(filepath, 'w') as f:
            for key, value in self.__dict__.items():
                f.write(f"{key}: {value}\n")

## 3.7 面向对象的好处

### 好处1：数据和操作打包

```python
# 以前（面向过程）：数据和函数分开
data = read_csv("data.csv")
results = analyze(data)       # 函数
plot(results)                 # 函数

# 现在（面向对象）：数据和方法在一起
analyzer = DiffExpAnalyzer("data.csv")  # 创建对象时就读好数据
analyzer.analyze()            # 方法
analyzer.export_results()     # 方法
```

### 好处2：多个实例互不干扰

```python
# 可以同时分析两个不同的数据集
analyzer1 = DiffExpAnalyzer("data1.csv")
analyzer2 = DiffExpAnalyzer("data2.csv")

results1 = analyzer1.analyze(...)
results2 = analyzer2.analyze(...)

# analyzer1 和 analyzer2 是完全独立的对象
print(analyzer1.results.shape)  # 数据集1的结果
print(analyzer2.results.shape)  # 数据集2的结果
```

### 好处3：代码组织清晰

- `DiffExpAnalyzer` 只管差异分析
- `GeneClassifier` 只管机器学习
- `PlotGenerator` 只管画图
- 各自独立，互不干扰

### 练习2：写一个图书类

```python
class Book:
    """图书类"""
    
    def __init__(self, title, author, price):
        self.title = title
        self.author = author
        self.price = price
        self.is_borrowed = False
    
    def borrow(self):
        """借书"""
        if not self.is_borrowed:
            self.is_borrowed = True
            print(f"《{self.title}》已借出")
        else:
            print(f"《{self.title}》已被借走")
    
    def return_book(self):
        """还书"""
        self.is_borrowed = False
        print(f"《{self.title}》已归还")
    
    def get_info(self):
        """获取图书信息"""
        status = "已借出" if self.is_borrowed else "在馆"
        return f"《{self.title}》作者：{self.author}，价格：{self.price}元，状态：{status}"

# 测试

book1.return_book()
```
