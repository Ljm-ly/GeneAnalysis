# Python 编程基础学习路线图

> 本路线图专为编程小白设计，从零开始循序渐进。

---

## 学习前准备

1. 安装 Python 3.10+
2. 安装一个代码编辑器（推荐 VS Code）
3. 确认能运行项目：`pip install -r requirements.txt`

## 学习方法建议

1. **每天只学1-2个知识点**，贪多嚼不烂
2. **学完后立刻做练习题**，不要只看不动手
3. **不懂就查**，善用搜索引擎
4. **多报错是好事**，报错是最好的老师
5. **给自己做小项目**，比如写一个计算器类

---

## 遇到问题怎么办？

| 问题类型 | 解决方法 |
|---------|---------|
| 概念不懂 | 回头再看一遍文档，或搜索更简单的解释 |
| 代码报错 | 仔细看报错信息，定位到具体行号 |
| 报错看不懂 | 把报错信息复制到搜索引擎 |
| 不知道怎么练 | 从练习题集找对应的题目 |
| 学不下去 | 休息一天，或换个知识点学 |
