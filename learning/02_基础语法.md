## 2.1 变量 —— 数据的"容器"

### 什么是变量？

变量就像一个**贴了标签的盒子**，盒子里可以装各种数据。

```python
age = 25          # 盒子上贴"age"，里面装数字 25
name = "张三"     # 盒子上贴"name"，里面装文字"张三"
```

### 命名规则

- 只能包含字母、数字、下划线
- 不能以数字开头
- 不能用 Python 关键字（如 if、for、class）

**好名字 vs 坏名字**：
```python
# 好的名字（一看就懂）
student_name = "张三"
gene_count = 1000
is_significant = True

# 坏的名字（看不懂）
a = "张三"        # a 是什么？
x1 = 1000        # x1 是什么？
flag = True      # flag 代表什么？
```

**项目中的变量命名**（都是好名字）：
```python
p_value_threshold = 0.05          # P值阈值，一看就懂
log2_fold_change_threshold = 1.0  # log2倍数变化阈值
n_estimators = 100                # 估计器数量
gc_window_size = 100              # GC分析窗口大小
```

## 2.2 基本数据类型

### 2.2.1 整数 (int)

没有小数点的数字。

```python
age = 25
year = 2024
gene_count = 1000
```

**数学运算**：
```python
a = 10
b = 3

a + b    # 13  加法
a - b    # 7   减法
a * b    # 30  乘法
a / b    # 3.33 除法（结果变成小数）
a // b   # 3   整除（只保留整数部分）
a % b    # 1   取余（10除以3余1）
a ** b   # 1000 幂运算（10的3次方）
```

### 2.2.2 浮点数 (float)

有小数点的数字。

```python
pi = 3.14159
p_value = 0.05
threshold = 1.5
```

**注意**：浮点数可能有精度问题
```python
0.1 + 0.2    # 结果不是 0.3，而是 0.30000000000000004
```

项目中的用法：
```python
# config.py
p_value_threshold: float = 0.05
test_size: float = 0.2
```

### 2.2.3 字符串 (str)

文字、文本，用引号包起来。

```python
name = "张三"
greeting = '你好'
path = "data/simulated_genes.fasta"
```

**单引号和双引号都可以**，但要配对：
```python
text1 = 'Hello'
text2 = "Hello"
# text3 = 'Hello"   # 错误！引号不配对
```

**字符串操作**：
```python
text = "Hello Python"

len(text)           # 12，字符串长度
text.upper()        # "HELLO PYTHON"，转大写
text.lower()        # "hello python"，转小写
text.split(" ")     # ["Hello", "Python"]，按空格分割
"Py" in text        # True，判断是否包含
```

**项目中的字符串**：

### 2.2.4 布尔值 (bool)

只有两个值：`True`（真）和 `False`（假）。

```python
is_significant = True
has_error = False
```

**比较运算产生布尔值**：
```python
5 > 3     # True
5 < 3     # False
5 == 5    # True  （注意是两个等号！）
5 != 3    # True  （!= 表示不等于）
3 >= 3    # True  （大于等于）
3 <= 5    # True  （小于等于）
```

**项目中的布尔值**（判断显著性）：
```python
# differential.py
results_df['is_significant'] = (
    (results_df['corrected_p_value'] < p_threshold) &
    (abs(results_df['log2_fold_change']) > log2fc_threshold)
)
# 结果是一个 True/False 的列
```

### 2.2.5 列表 (list)

有序的数据集合，用方括号 `[]`。

```python
fruits = ["苹果", "香蕉", "橙子"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]  # 可以混装不同类型
```

**索引（取元素）—— 从 0 开始！**：
```python
fruits = ["苹果", "香蕉", "橙子"]

fruits[0]    # "苹果"  （第1个，索引是0）
fruits[1]    # "香蕉"  （第2个，索引是1）
fruits[2]    # "橙子"  （第3个，索引是2）
fruits[-1]   # "橙子"  （倒数第1个）
fruits[-2]   # "香蕉"  （倒数第2个）
```

**常用操作**：
```python
fruits = ["苹果", "香蕉"]

# 添加元素
fruits.append("橙子")        # ["苹果", "香蕉", "橙子"]

# 修改元素
fruits[0] = "西瓜"           # ["西瓜", "香蕉", "橙子"]

# 删除元素
fruits.remove("香蕉")        # ["西瓜", "橙子"]

# 查看长度
len(fruits)                  # 2

# 切片（取一部分）
numbers = [0, 1, 2, 3, 4, 5]
numbers[1:4]    # [1, 2, 3]  （从索引1到3，不包含4）
numbers[:3]     # [0, 1, 2]  （从开头到2）
numbers[3:]     # [3, 4, 5]  （从3到末尾）
```

**项目中的列表**：

### 2.2.6 字典 (dict)

### 2.2.7 元组 (tuple)

和列表很像，但**创建后不能修改**。用圆括号 `()`。

```python
point = (10, 20)           # 坐标点
size = (10, 8)             # 图表尺寸
rgb = (255, 128, 0)        # 颜色值
```

**为什么不能修改？**

因为元组用来表示"固定不变"的数据，比如配置参数。这样别人（或未来的你）不会意外改错。

```python
# 可以读
size = (10, 8)
width = size[0]    # 10
height = size[1]   # 8

# 不能改
size[0] = 12       # 报错！TypeError
```

**项目中的元组**：
```python

```

### 数据类型小结

| 类型 | 表示 | 例子 | 特点 |
|------|------|------|------|
| int | 整数 | `100` | 没有小数 |
| float | 浮点数 | `3.14` | 有小数 |
| str | 字符串 | `"hello"` | 用引号包 |
| bool | 布尔值 | `True`/`False` | 只有两种值 |
| list | 列表 | `[1, 2, 3]` | 有序，可修改 |
| dict | 字典 | `{"a": 1}` | 键值对 |
| tuple | 元组 | `(1, 2)` | 有序，不可修改 |

## 2.3 条件判断 —— if/elif/else

### 基本语法

```python
if 条件:
    # 条件为 True 时执行
    做这件事
else:
    # 条件为 False 时执行
    做另一件事
```

**缩进很重要！** Python 用缩进（通常是4个空格）表示代码块。

```python
age = 18

if age >= 18:
    print("成年了")
else:
    print("未成年")
```

### 多条件判断 elif

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")      # 85满足这个条件，打印"良好"
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**执行规则**：从上到下判断，满足一个就执行对应的代码，然后跳过其他的。

### 嵌套判断

```python
age = 20
money = 100

if age >= 18:
    if money >= 50:
        print("可以买票")
    else:
        print("钱不够")
else:
    print("年龄不够")
```

### 逻辑运算符

```python
# and：两个条件都要满足
if age >= 18 and money >= 50:
    print("可以买票")

# or：满足一个就行
if age >= 60 or age <= 6:
    print("免票")

# not：反过来
if not is_raining:
    print("去跑步")
```

**项目中的条件判断**：
```python

    (results_df['corrected_p_value'] < p_threshold) &      # 条件1
    (abs(results_df['log2_fold_change']) > log2fc_threshold)  # 条件2
)

# 判断调控方向
results_df['regulation'] = 'no_change'
results_df.loc[results_df['log2_fold_change'] > log2fc_threshold, 'regulation'] = 'up'
results_df.loc[results_df['log2_fold_change'] < -log2fc_threshold, 'regulation'] = 'down'

# classifier.py - 检查样本数量

    self.logger.error("训练样本太少")
    return {'error': 'Too few samples'}
```

## 2.4 循环 —— for 和 while

### 2.4.1 for 循环（最常用）

逐个处理列表中的元素。

```python
fruits = ["苹果", "香蕉", "橙子"]

for fruit in fruits:
    print(fruit)

# 输出：
# 苹果
# 香蕉
# 橙子
```

**配合 range() 使用**：

```python
# range(5) 生成 [0, 1, 2, 3, 4]
for i in range(5):
    print(i)

# range(1, 6) 生成 [1, 2, 3, 4, 5]（包含1，不包含6）
for i in range(1, 6):
    print(i)

# range(0, 10, 2) 生成 [0, 2, 4, 6, 8]（步长为2）
for i in range(0, 10, 2):
    print(i)
```

**项目中的 for 循环**：
```python
# differential.py - 对每个基因执行t检验
for gene in genes:
    exp1 = group1_filtered.loc[gene]
    exp2 = group2_filtered.loc[gene]
    
    t_stat, p_value = self._perform_ttest(exp1, exp2)
    log2_fc = self._calculate_fold_change(exp1, exp2)
    
    results_list.append({
        'gene': gene,
        'log2_fold_change': log2_fc,
        'p_value': p_value,
        ...
    })
```

这段代码的意思是：遍历每个基因，取出它在对照组和处理组的数据，做 t 检验，计算倍数变化，把结果存到列表里。

### 2.4.2 enumerate() —— 同时获取索引和元素

```python

    print(f"第{i}个是{fruit}")

# 输出：
# 第0个是苹果
# 第1个是香蕉
# 第2个是橙子
```

**项目中的 enumerate**：

### 2.4.3 while 循环

满足条件就一直循环。

```python
count = 0
while count < 5:
    print(count)
    count += 1   # count = count + 1，必须让条件会变为False，否则会无限循环

# 输出：0 1 2 3 4
```

### 2.4.4 break 和 continue

```python
# break：跳出循环
for i in range(10):
    if i == 5:
        break       # 到5就停止，不继续了
    print(i)        # 输出：0 1 2 3 4

# continue：跳过当前次，继续下一次
for i in range(5):
    if i == 2:
        continue    # 跳过2
    print(i)        # 输出：0 1 3 4
```

## 2.5 函数 —— 代码的"打包工具"

### 2.5.1 为什么要用函数？

想象你在做一道复杂的菜，步骤很多。函数就是把一组操作打包，起个名字，以后直接调用。

**不用函数**（重复写代码）：
```python
# 计算第一个学生的平均分
score1 = [80, 90, 85]
avg1 = sum(score1) / len(score1)

# 计算第二个学生的平均分（重复！）
score2 = [75, 88, 92]
avg2 = sum(score2) / len(score2)
```

**用函数**（一行搞定）：
```python
def calculate_average(scores):
    return sum(scores) / len(scores)

avg1 = calculate_average([80, 90, 85])
avg2 = calculate_average([75, 88, 92])
```

### 2.5.2 定义函数的语法

```python
def 函数名(参数1, 参数2, ...):
    """文档字符串（说明函数做什么）"""
    # 函数体（具体代码）
    ...
    return 返回值
```

**例子**：
```python
def greet(name):
    """向某人问好"""
    message = f"你好，{name}！"
    return message

# 调用函数
result = greet("张三")
print(result)   # 你好，张三！
```

### 2.5.3 参数和返回值

```python
# 没有参数，没有返回值
def say_hello():
    print("Hello")

# 有参数，没有返回值
def print_name(name):
    print(f"Name: {name}")

# 没有参数，有返回值
def get_pi():
    return 3.14159

# 有参数，有返回值
def add(a, b):
    return a + b
```

### 2.5.4 默认参数

参数可以有默认值，调用时可以不传。

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

# 不传 greeting，用默认值
greet("张三")           # 你好，张三！

# 传自定义的 greeting
greet("李四", "早上好")  # 早上好，李四！
```

**项目中的默认参数**：
```python

    ...
```

### 2.5.5 项目中的函数实例

```python
# data_cleaner.py - 去除重复值
def remove_duplicates(self, df):
    """去除数据框中的重复行"""
    original_len = len(df)
    df_clean = df.drop_duplicates(keep='first')
    removed = original_len - len(df_clean)
```

3. 记录日志
4. 返回去重后的数据框

## 2.6 字符串格式化 —— f-string

### 什么是 f-string？

在字符串前加 `f`，然后在字符串里用 `{}` 插入变量。

```python
name = "张三"
age = 20

# 普通写法（麻烦）
message = "我是" + name + "，今年" + str(age) + "岁"

# f-string（简洁）
message = f"我是{name}，今年{age}岁"
```

### 格式化数字

```python
pi = 3.1415926

f"{pi}"         # "3.1415926"
f"{pi:.2f}"     # "3.14"     保留2位小数
f"{pi:.4f}"     # "3.1416"   保留4位小数
f"{1000:,}"     # "1,000"    千分位分隔
```

**项目中的 f-string**：
```python
# 到处都在用
self.logger.info(f"成功读取表达数据: {self.data.shape}")
self.logger.info(f"平均GC含量: {avg_gc:.2f}%")
ax.axvline(mean_val, label=f'均值: {mean_val:.1f}%')
```

## 2.7 文件操作基础

### 读取文件

```python
# 方式1：一次性读完
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 方式2：逐行读取
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())  # strip()去掉首尾空白
```

### 写入文件

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, World!\n")
```

**with 语句的好处**：自动关闭文件，不用写 `f.close()`。

## 2.8 实用小技巧
